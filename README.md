## TOPMODEL in R

An R implementation of TOPMODEL, the rainfall-runoff model originally written in Fortran by [Beven (1995)](https://hess.copernicus.org/articles/25/527/2021/). 
Whilst other (conversions)[https://github.com/ICHydro/topmodel/tree/master/topmodel] from the original Fortran to R already exist. I'm writing my own for two reasons:

- **To learn.** I want to understand how R packages are built and how they develop over time.
- **To use it.** I work with TOPMODEL, so an easily accessible version is helpful.
